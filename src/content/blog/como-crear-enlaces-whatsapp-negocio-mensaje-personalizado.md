## ⚡ TL;DR

- **Estructura oficial:** La API oficial de WhatsApp utiliza el formato internacional `https://wa.me/<telefono>?text=<mensaje_codificado>`.
- **Formato del número:** Debe incluir el prefijo del país sin ceros iniciales ni signos `+` ni guiones (por ejemplo, para España: `34612345678`).
- **Codificación URL:** Los espacios deben convertirse en `%20` y los saltos de línea en `%0A` para que no se rompa el hipervínculo en navegadores.
- **Generador automático:** Crea tu enlace listo para copiar en 2 segundos con nuestro [Generador de Enlaces de WhatsApp con Texto](/herramientas/generador-link-whatsapp).

## 📲 ¿Por qué necesitas un enlace de WhatsApp directo?

En el comercio electrónico y la atención al cliente moderna, la fricción es el principal enemigo de la conversión:

1. **Elimina la necesidad de guardar el contacto:** El cliente no tiene que añadir tu número a su agenda para iniciar una conversación comercial.
2. **Mensajes preconfigurados:** Puedes preparar textos de inicio contextuales según de dónde venga el usuario: *"Hola, vi este producto en Instagram y me gustaría saber el precio de envío"*.
3. **Optimizado para el botón de perfil (Link in Bio):** Esencial para biografías de Instagram, perfiles de TikTok, fichas de Google Business Profile y botones flotantes web.

## 🛠️ Cómo funciona la sintaxis de la API wa.me

### 1. Enlace simple sin mensaje
```text
https://wa.me/34600112233
```
Al hacer clic, abre WhatsApp directamente en la conversación con ese número.

### 2. Enlace con mensaje personalizado
Si quieres que el usuario inicie la charla con un texto específico:
```text
https://wa.me/34600112233?text=Hola%2C%20quiero%20m%C3%A1s%20informaci%C3%B3n%20sobre%20vuestros%20servicios
```

### Tabla de caracteres especiales frecuentes

| Carácter | Código URL Encoded | Ejemplo |
| :--- | :--- | :--- |
| **Espacio** | `%20` | `Hola%20quiero` |
| **Coma ( , )** | `%2C` | `Hola%2C%20buenos` |
| **Salto de línea** | `%0A` | Primera línea`%0A`Segunda línea |
| **Interrogación ( ? )** | `%3F` | `precio%3F` |
| **Arroba ( @ )** | `%40` | `contacto%40empresa.com` |
